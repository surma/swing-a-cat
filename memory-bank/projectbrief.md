# Project Brief: To Swing a Cat

## Contest Context
- **Competition**: js13k 2025
- **Size Limit**: 13KB zipped
- **Technology**: JavaScript/TypeScript web game

## Core Concept
A pixel art platformer where you play as a cat that collects tails to gain new abilities and swing through levels.

## Game Mechanics
- **Character**: Cat protagonist
- **Core Mechanic**: Swinging using tail(s)
- **Progression**: Collect more tails → unlock new abilities
- **Movement**: Physics-based swinging mechanics
- **Style**: Pixel art aesthetic

## Technical Requirements
- **Audio**: Custom music using SoundBox
- **Sound Effects**: zzfx library for procedural audio
- **Graphics**: Pixel art style with crisp rendering
- **Size**: Must fit within 13KB compressed

## Success Criteria
1. Engaging swinging mechanics that feel good to control
2. Clear progression system tied to tail collection
3. Visually appealing pixel art style
4. Memorable audio experience
5. Fits within js13k size constraints
6. Complete, playable game experience

## Target Experience
Players should feel the satisfaction of mastering the swinging mechanics while discovering new abilities as they collect tails, creating a sense of progression and exploration.
