# Product Context: To Swing a Cat

## Why This Game Exists
"To Swing a Cat" is designed to explore the joy of momentum-based movement in a constrained environment. The js13k contest provides the perfect challenge to create a focused, polished experience within strict size limits.

## Problems It Solves
- **Movement Mastery**: Provides satisfying physics-based movement that rewards skill development
- **Progression Clarity**: Uses a simple, visual metaphor (collecting tails) for character growth
- **Accessibility**: Easy to understand concept with depth in execution
- **Replayability**: Skill-based movement encourages multiple playthroughs to master levels

## How It Should Work

### Core Loop
1. **Explore** → Navigate levels using basic swinging mechanics
2. **Collect** → Find and gather tail collectibles
3. **Evolve** → Unlock new abilities tied to tail count
4. **Master** → Use new abilities to access previously unreachable areas

### Player Experience Journey
- **Initial**: Learn basic swinging with single tail
- **Discovery**: Find first additional tail, unlock new ability
- **Exploration**: Use new abilities to reach new areas
- **Mastery**: Combine all abilities for fluid, skilled movement

### Emotional Beats
- **Wonder**: "What can I reach with this tail?"
- **Achievement**: "I collected another tail!"
- **Empowerment**: "Now I can do things I couldn't before!"
- **Flow**: "I'm swinging through this level like a master!"

## User Experience Goals

### Immediate (First 30 seconds)
- Player understands they control a cat
- Basic swinging feels responsive and fun
- Visual style is immediately appealing
- Audio creates atmosphere

### Short-term (First 5 minutes)
- Player has mastered basic swinging
- First tail collection feels rewarding
- New ability is clearly communicated
- Player wants to explore more

### Long-term (Full playthrough)
- Player feels genuine progression
- Movement becomes second nature
- All abilities work together fluidly
- Player wants to replay for better performance

## Success Metrics
- Player completes tutorial without confusion
- Player actively seeks out tail collectibles
- Player experiments with new abilities immediately upon unlock
- Player replays levels to improve their performance
